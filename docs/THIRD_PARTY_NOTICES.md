# Third-party notices

The production interface bundles React, React DOM, Scheduler, Three.js,
Lucide icons, DM Sans, and Cormorant Garamond. Their license texts are included
in `licenses/`. Versions are pinned in `shared/ui/package-lock.json`.
Three-dimensional pieces and the two-dimensional piece symbols are original
procedural artwork created for this project. Fonts are served locally.

Python and development dependencies are installed separately through their
package managers; their own distributions carry their licenses. This notice
does not assign a new license to the original project source.
